Arcade Box — ne indirilir, hangi oyun hangi core
================================================

Tek program: RetroArch (portable)
  Windows: retroarch.exe  ->  emulators/retroarch/
  Linux:   retroarch      ->  emulators/retroarch/  veya  apt install retroarch

Core'lar RetroArch icinde:
  Online Updater  ->  Core Downloader

Windows dosyasi .dll, Linux .so  (isim ayni, uzanti farkli)
Hepsini koy: emulators/retroarch/cores/
